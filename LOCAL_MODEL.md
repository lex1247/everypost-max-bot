# Бесплатное автоматическое переписывание

Это экспериментальный адаптер llama-server, который пока не включён. Проверки на Intel Mac с 8 ГБ памяти показали, что Qwen3-4B Q4_K_M, Qwen3.5-2B Q4_K_M и отдельный ruT5-перефразировщик меняют или теряют факты. В отдельных случаях проверка самой модели ошибочно принимала такие изменения. Эти модели нельзя считать готовым решением для выбранного источника; их тестовые пересказы не публиковались.

Код можно использовать с другой локальной моделью после проверки качества. Компьютер должен оставаться включённым. Ниже сохранены данные для воспроизведения первого эксперимента, а не рекомендация включить эту модель в автоматическом режиме.

## Проверенные файлы

- [llama.cpp b10930 для Intel Mac](https://github.com/ggml-org/llama.cpp/releases/tag/b10930), архив `llama-b10930-bin-macos-x64.tar.gz`.
  SHA-256: `eb9104c2b9d005e3e08dd79abc57417c8e20e8cecfc4435a946d204b2e289d5c`.
- [Официальная модель Qwen3-4B-GGUF](https://huggingface.co/Qwen/Qwen3-4B-GGUF/tree/bc640142c66e1fdd12af0bd68f40445458f3869b), файл `Qwen3-4B-Q4_K_M.gguf`.
  SHA-256: `7485fe6f11af29433bc51cab58009521f205840f5b4ae3a32fa7f92e8534fdf5`.

Для другой ОС нужен соответствующий бинарный файл llama-server. Большие файлы модели и программы не включены в ZIP бота.

## Настройка

Распакуй программу с её библиотеками в одну папку и скачай модель. Укажи в `.env`:

```dotenv
FREE_TEST_MODE=1
LLM_PROVIDER=local
LOCAL_LLM_URL=http://127.0.0.1:18081
LOCAL_MODEL_NAME=everypost-local
LLAMA_SERVER_PATH=/полный/путь/к/llama-server
LOCAL_MODEL_PATH=/полный/путь/к/Qwen3-4B-Q4_K_M.gguf
```

`OPENAI_API_KEY` и `OPENAI_MODEL` для этого режима не нужны. При запуске `python app.py` бот запускает модель, дожидается готовности и начинает обрабатывать накопленные посты. Пауза публикаций сохраняется между перезапусками. При штатной остановке бота модель тоже останавливается.

Для модели, запущенной отдельно, оставь `LLAMA_SERVER_PATH` пустым. Сервер должен слушать только `127.0.0.1`, использовать то же имя модели и отключённый thinking. Справка: [llama-server](https://github.com/ggml-org/llama.cpp/tree/master/tools/server).

## Поведение

- Сбор источников продолжается во время переписывания. Одновременно выполняется один запрос к модели.
- Сначала модель переписывает текст, затем отдельно сравнивает с оригиналом. Числа, ссылки и @имена дополнительно проверяются кодом.
- Незавершённый ответ или отрицательная проверка блокируют пост; он появляется в `/errors`. Повтор после исправления причины — `/retry_post НОМЕР`.
- При временной недоступности модели оригинал остаётся в очереди, бот повторяет попытку. Платного запасного сервиса нет.
- Контекст ограничен 4096 токенами для экономии памяти. Слишком длинный текст может потребовать ручной обработки; тихого обрезания нет.
- В локальный сервер не передаются токены Telegram, MAX, ВК или OpenAI. Прокси и перенаправления для запросов модели отключены.
- Фото, видео и альбомы пока не переносятся. В канал отправляется переписанный текст и ссылка на оригинал.

Если процесс модели аварийно завершился, перезапусти бота. Диагностика запуска — `data/local-model.log`.
