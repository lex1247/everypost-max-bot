# Бесплатный онлайн-тест

Режим выбирается кнопкой «Режим публикации» отдельно для каждой связки источника и канала. «Как есть» отправляет исходный текст без запросов к ИИ. «Переписать с ИИ» использует согласованный провайдер ниже. В обоих режимах JPEG/PNG-фотографии и фотоальбомы переносятся, а служебная ссылка «Источник» не добавляется. Фотографии в ИИ не передаются.

13 сентября 2026 года проверена реальная отправка фото с переписанным текстом в подключённый канал MAX. В тестовом Telegram-канале добавлены две ранее пропущенные фотографии и удалены служебные ссылки из шести тестовых сообщений. Обновлённый локальный процесс запущен, связки Telegram и MAX включены в режиме ИИ. Проверки кода: 99 тестов прошли; после исправления доверенных сертификатов сервера загрузки MAX повторно прошли 52 затронутых теста.

LLM7 документирует анонимный доступ к текстовому API без регистрации и без платёжного ключа: [быстрый старт](https://docs.llm7.io/quickstart), [лимиты](https://docs.llm7.io/limits). На 12 сентября 2026 года в документации указаны 10 запросов в минуту, 60 в час и 500 000 токенов за 24 часа для анонимного режима. Доступность и лимиты могут меняться.

Владелец согласовал передачу текстов в LLM7. Реальные запросы выполнены с анонимной авторизацией. Селектор `default` дал непригодные результаты; для проверки выбран `minimax-m2.7`. Проверка отдельных постов не гарантирует безошибочную обработку любого текста: сомнительные варианты должны оставаться для ручного разбора.

12 сентября 2026 года четыре поста выбранного источника прошли проверку и ручной просмотр результата. Два контрольных искажения — удалённая оговорка о бренде и выдуманное авторство фотографии — были отклонены проверкой с объяснением причины. Бесплатная обработка включена в локальном процессе; оплачиваемые API не включались.

После согласования разработчик устанавливает:

```dotenv
FREE_TEST_MODE=1
LLM_PROVIDER=llm7
LLM7_APPROVED=1
LLM7_MODEL=minimax-m2.7
```

Перед запуском нужно проверить качество реальных пересказов без публикации, затем перезапустить основной процесс. Интеграция использует только фиксированный адрес `https://api.llm7.io/v1/chat/completions` и анонимное значение `Bearer unused`. Ключи платного аккаунта, Telegram, MAX и ВК этому сервису не передаются.

В сервис уходят редакторское задание, исходный текст поста, затем оригинал и пересказ для проверки. Поэтому согласование нужно до первого реального запроса. Авторизация платного аккаунта и автоматическое переключение на другой платный API не предусмотрены.

Бот выдерживает минимум 15 секунд между запросами и ограничивает себя 55 запросами в час. Счётчик хранится в SQLite и сохраняется при перезапуске. Каждый обычный пост требует двух запросов; при провале проверки возможна одна дополнительная попытка. При ответе 429 учитывается Retry-After; во время недоступности сервиса посты остаются в очереди. Пустые, незавершённые и не прошедшие проверку пересказы не публикуются. Для рассуждающей модели оставлен запас токенов на проверку, даже когда видимый ответ — только OK/FAIL.

Бот по-прежнему работает на компьютере, пока он включён и не спит. Отдельного круглосуточного развёртывания этой версии нет.
