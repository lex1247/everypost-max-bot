# Сертификат для MAX

`russian-trusted-root.pem` скачан 12 сентября 2026 года с официального статического домена Госуслуг:

https://gu-st.ru/content/lending/russian_trusted_root_ca_pem.crt

SHA-256 файла: `936a43fea6e8e525bcc0f81acd9c3d21b4fc4b9b68acea7906d698005afc6504`.

Документация MAX требует использовать `platform-api2.max.ru` и доверять сертификату Минцифры: https://dev.max.ru/docs-api/methods/GET/me.

Сертификат добавляется только в SSLContext отдельного HTTP-клиента MAX, поверх стандартного набора публичных корней `certifi`, который использует httpx. Публичные корни нужны для сервера загрузки фотографий `iu.oneme.ru`. Проверка имени сервера и цепочки сертификатов включена. Системное хранилище, браузер и остальные HTTP-клиенты не меняются. Проверены соединения с API MAX и сервером загрузки без отключения TLS-проверок.
